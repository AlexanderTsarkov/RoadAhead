Phase 0 validation emulator · not the final delivery surface

Baseline placeholder

This app is the Phase 0 interactive web route emulator for the RoadAhead project. It is a research and validation tool only — not the final delivery surface, not a production app, and not a driver-facing product.

Emulator behavior (route simulation, event applicability, UI model) will be introduced in subsequent implementation slices under Issue #17. This slice (Issue #41) establishes the app baseline only.

Product Canon guardrails

  • RoadAhead is not a navigator.
  • RoadAhead is not an anti-radar.
  • RoadAhead is not a legal speed-limit authority.
  • RoadAhead is not safety-certified.
  • External road-event data is candidate input only, not verified RoadAhead truth.
  • Raw Datakam / OpenSpeedcam data is import / source material only.
  • Route provider data may supply geometry only; provider non-geometry signals are not RoadAhead truth.
  • No numeric tuning value is Product Canon at this stage.

Product Canon is the primary authority. See docs/product/areas/ in the repository. This emulator is a WIP validation tool; its behavior and any numeric defaults it will use in later slices are WIP only and require validation evidence before any Canon promotion.

What this baseline does not include

  • No route geometry or route rendering
  • No prepared event fixtures
  • No Datakam import
  • No event applicability logic
  • No speed-reference logic
  • No feedback / enforcement logic
  • No three-circle behavior
  • No numeric tuning values

These will be introduced in subsequent slices under Issue #17.
