# Route Events Directory

This directory holds **prepared route-scoped event datasets** for use by the emulator.

## What belongs here

- Prepared bounded event datasets generated by `scripts/prepareRouteEvents.mjs`
- Format: `<RouteName>.events.json` (e.g. `Rostov1.events.json`)
- These files are route-scoped / bounded — not raw source data

## What does NOT belong here

- Raw OpenSpeedcam / Datakam CSV files (gitignored, local only)
- Any file containing raw source rows not filtered to a route corridor

## Data policy

- Raw source files remain local and are gitignored (`data/raw/*`)
- Prepared output may be committed only when explicitly approved for emulator use
- Every prepared file must have `source.raw_source_committed = false`

## How to generate a prepared dataset

From `web/roadahead-emulator/`:

```bash
npm run prepare:route-events -- \
  --route public/routes/Rostov1.geojson \
  --raw ../../data/raw/datakam/openspeedcam.csv \
  --route-id rostov1 \
  --buffer-m 3000 \
  --out public/route-events/Rostov1.events.json
```

The raw file path must exist locally (gitignored). The output file can then be
committed if explicitly approved.
